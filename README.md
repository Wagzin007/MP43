# MP43

Baixador de vídeos em MP4 e áudio em MP3 com interface Tkinter.

## Como executar

1. Instale as dependências:

	```bash
	python -m pip install -r requirements.txt
	```

2. Para conversão para MP3, instale o `ffmpeg` no sistema e deixe-o disponível no `PATH`.

3. Inicie o programa:

	```bash
	python main.py
	```

Cole uma URL, selecione o formato, escolha a pasta de destino e clique em **Baixar**.
